# People Import CSV Guide

Use the People Import CSV Template when preparing bulk people records.

## Workflow

1. Open the app Reports page.
2. Click Download People Import Template.
3. Open the CSV in Excel.
4. Fill in one person per row.
5. Save as CSV UTF-8.
6. Import using the future People Import page.

## Required Fields

- firstname
- lastname

## Recommended Fields

- sex
- birthdate
- locality
- contact_number
- church_status
- shepherding_group
- household_name

## Date Format

Use this format:

YYYY-MM-DD

Example:

2001-05-24

## Sex Values

Use:

Male
Female

## Church Status Values

Use one of these:

Active
Full-Timer
New One
Gospel Friend
Dormant
Moved
Deceased
Unknown

## Shepherding Group Values

Use one of these:

Children (Toddler-Kinder)
Children (G1-G4)
Junior Young People (G5-G7)
Young People (G8-G10)
Collegian (G11-C1)
Collegian (C2-Graduating)
Young Adults (Graduates - Age 45)
Middle Age (Age 46 - Age 59)
Elderly (Age 60 - Above)

## Notes

- Do not rename the CSV headers.
- Do not merge cells.
- Do not add formulas.
- Save as CSV UTF-8.
- One row equals one person.
- Empty optional fields are allowed.
- The import page will validate the file before saving records.
